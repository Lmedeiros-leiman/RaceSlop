# M2 Plan 02 — Character Roster (4 Reskins)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four characters as data + a `buildKartMesh` factory, replacing the hardcoded red kart, with identical handling for everyone.

**Architecture:** `characters.ts` holds the roster as `CharacterDef[]` (palette + silhouette multipliers, visual only) and `buildKartMesh(def)` — the M1 placeholder kart extracted from `main.ts`, parameterized by the def. `main.ts` builds `CHARACTERS[0]` until the select flow lands (Plan 04). Physics, `KartParams`, and `stepKart` are untouched: identical handling is structural (no per-character params exist).

**Tech Stack:** TypeScript (strict), vitest, Three.js.

**Spec:** `docs/SPEC-M2.md` §6 (roster), §10 (module structure).

**Depends on:** nothing (independent of Plans 00/01; can run in parallel).

## Global Constraints

- TypeScript strict mode, no `any` in game code.
- A single `DEFAULT_PARAMS` for all characters — no per-character stats.
- Silhouette multipliers scale geometry only; wheels stay stock size.
- `npm test` and `npm run build` must stay green.

```ts
import * as THREE from 'three';

// M1 placeholder kart (SPEC-M1 §9) parameterized by the character def:
// body in def.body, nose in def.accent, box dims scaled by silhouette.
export function buildKartMesh(def: CharacterDef): THREE.Group {
  const { width: w, height: h, length: l } = def.silhouette;
  const kartMesh = new THREE.Group();

  const body = new THREE.Mesh(
    new THREE.BoxGeometry(1 * w, 0.5 * h, 2 * l),
    new THREE.MeshStandardMaterial({ color: def.body, flatShading: true }),
  );
  body.name = 'body';
  body.position.y = 0.45 * h;
  kartMesh.add(body);

  const nose = new THREE.Mesh(
    new THREE.BoxGeometry(0.6 * w, 0.2, 0.4 * l),
    new THREE.MeshStandardMaterial({ color: def.accent, flatShading: true }),
  );
  nose.name = 'nose';
  nose.position.set(0, 0.4 * h, 1.1 * l);
  kartMesh.add(nose);

  const wheelGeo = new THREE.CylinderGeometry(0.22, 0.22, 0.25, 12);
  const wheelMat = new THREE.MeshStandardMaterial({ color: 0x181818, flatShading: true });
  for (const [wx, wz] of [
    [-0.6, 0.7],
    [0.6, 0.7],
    [-0.6, -0.7],
    [0.6, -0.7],
  ] as const) {
    const wheel = new THREE.Mesh(wheelGeo, wheelMat);
    wheel.rotation.z = Math.PI / 2;
    wheel.position.set(wx, 0.22, wz);
    kartMesh.add(wheel);
  }

  return kartMesh;
}
```
