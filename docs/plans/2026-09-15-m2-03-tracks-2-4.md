# M2 Plan 03 — Tracks 2–4 (Circuit, Park, Neon)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the three new `TrackDef`s — technical circuit (walls, chicanes), off-road park (narrow, soft shoulders), neon night (wide sweepers, dark theme) — each passing `validateTrackDef`, with tests and a visual driving pass.

**Architecture:** Each task is one def in `src/game/tracks.ts` (pure data + theme) validated two ways: `validateTrackDef` (closure position + heading, radius floor, straight start, no self-intersection, checkpoint spacing) and explicit target tests (lap length from `sampleTrack(def).length`, boundary fields, theme pins). No engine changes — Plan 00 provides everything. Each layout is point-symmetric (identical half-lists, net heading π each), which guarantees closure and puts start/finish mid-straight; the halves occupy opposite quadrant pairs, so no self-intersection (verified by trace, re-verified by the validator and visually).

**Tech Stack:** TypeScript (strict), vitest.

**Spec:** `docs/SPEC-M2.md` §5 (track table + design constraints), §4 (validation).

**Depends on:** Plan 00 (`Segment`, `TrackDef`, `buildTrack`, `validateTrackDef`, `sampleTrack`, `DEFAULT_THEME`).

## Global Constraints

- TypeScript strict mode, no `any` in game code.
- Segment convention from Plan 00: start `(0, 0)` heading `0` (`f(h) = (sin h, cos h)`), positive angle increases heading (`+π/2` arc facing `+z` ends at `(r, r)`).
- Lap lengths (from `sampleTrack(def).length`): circuit 650–750 m, park 600–900 m, neon 1000–1250 m.
- Min corner radius ≥ 18 m measured on the center-line (the inner edge is tighter by `halfWidth` — accepted per SPEC-M2 §5); start/finish on a straight; no self-intersecting layouts.
- Every def must pass `validateTrackDef` with zero errors.
- Park is the only `soft` track (shoulder 9 m); neon edge color must pop against dark asphalt.
- Track ids are stable persistence keys — never reused.
- `main.ts` stays on `OVAL_DEF` until Plan 04 — visual passes swap it temporarily and revert before commit.
- `npm test` and `npm run build` must stay green.
