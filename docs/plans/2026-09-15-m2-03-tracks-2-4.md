# M2 Plan 03 — Tracks 2–4 (Circuit, Park, Neon)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the three new `TrackDef`s — technical circuit (walls, chicanes), off-road park (narrow, soft shoulders), neon night (wide sweepers, dark theme) — with tests and a visual driving pass each.

**Architecture:** Each task is one def in `src/game/tracks.ts` (pure data + theme) validated by pure tests (length range, min radius, closure, sampling, boundary fields). No engine changes — Plan 00 provides everything. Each layout is point-symmetric (identical half-lists, net heading π each), which guarantees closure and puts start/finish mid-straight; the halves occupy opposite quadrant pairs, so no self-intersection (verified by trace, re-verified visually).

**Tech Stack:** TypeScript (strict), vitest.

**Spec:** `docs/SPEC-M2.md` §5 (track table + design constraints), §4 (closure rule).

**Depends on:** Plan 00 (`Segment`, `TrackDef`, `buildTrack`, `minRadius`, `pathLength`, `CHECKPOINT_COUNT`).

## Global Constraints

- TypeScript strict mode, no `any` in game code.
- Segment convention from Plan 00: start `(0, 0)` heading `0` (`f(h) = (sin h, cos h)`), positive angle increases heading (`+π/2` arc facing `+z` ends at `(r, r)`).
- Lap lengths: circuit 650–750 m, park 600–900 m, neon 1000–1250 m.
- Min corner radius ≥ 18 m everywhere; start/finish on a straight; no self-intersecting layouts.
- Park is the only `soft` track (shoulder 9 m); neon edge color must pop against dark asphalt.
- `main.ts` stays on `OVAL_DEF` until Plan 04 — visual passes swap it temporarily and revert before commit.
- `npm test` and `npm run build` must stay green.
