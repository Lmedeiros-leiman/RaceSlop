# M2 Plan 01 — Best-Lap Records

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist the best lap per track in `localStorage`, fail-soft on every storage failure, and make the HUD show the all-time best.

**Architecture:** `records.ts` has a pure core (`createRecordStore(load, save)`) injected with storage functions, so all logic is testable in the node vitest environment without `localStorage`. The browser adapter wraps every read and write in try/catch and mirrors the payload in memory, so private-mode reads and quota-exceeded writes degrade to a session-only store without ever throwing. The race loop seeds `LapTracker.best` from the store and writes every valid lap back. Comparisons use rounded centisecond values.

**Tech Stack:** TypeScript (strict), vitest.

**Spec:** `docs/SPEC-M2.md` §8 (records), §3 (storage decision).

**Depends on:** Plan 00 (track `id` keys the records; ids are stable persistence keys, never reused).

## Global Constraints

- TypeScript strict mode, no `any` in game code.
- Storage key `raceslop.records.v1`, schema `{"version":1,"best":{"<trackId>":<seconds>}}`.
- Centisecond precision on write; comparison on rounded values; worse-or-equal laps never overwrite.
- Unparsable or wrong-version payload → treated as empty; a throwing `load` → start empty; a throwing `save` → swallowed. Never throws.
- No `localStorage` access at import time (module must stay importable in node).
- `npm test` and `npm run build` must stay green.

```ts
export interface RecordStore {
  getBest(trackId: string): number | null;
  recordLap(trackId: string, seconds: number): boolean;
}

interface RecordsV1 {
  version: 1;
  best: Record<string, number>;
}

function parse(raw: string | null): RecordsV1 {
  if (raw === null) return { version: 1, best: {} };
  try {
    const data: unknown = JSON.parse(raw);
    if (
      typeof data === 'object' &&
      data !== null &&
      (data as RecordsV1).version === 1 &&
      typeof (data as RecordsV1).best === 'object' &&
      (data as RecordsV1).best !== null
    ) {
      return data as RecordsV1;
    }
  } catch {
    // corrupt payload: treat as empty
  }
  return { version: 1, best: {} };
}

export function createRecordStore(load: () => string | null, save: (v: string) => void): RecordStore {
  let data: RecordsV1;
  try {
    data = parse(load());
  } catch {
    // storage read threw (private mode): start empty
    data = { version: 1, best: {} };
  }
  return {
    getBest(trackId: string): number | null {
      const v = data.best[trackId];
      return typeof v === 'number' && Number.isFinite(v) ? v : null;
    },
    recordLap(trackId: string, seconds: number): boolean {
      const cs = Math.round(Math.max(0, seconds) * 100) / 100;
      const cur = data.best[trackId];
      if (typeof cur === 'number' && cs >= cur) return false;
      data.best[trackId] = cs;
      try {
        save(JSON.stringify(data));
      } catch {
        // storage write threw (quota): the session keeps the value
      }
      return true;
    },
  };
}
```

```ts
export const STORAGE_KEY = 'raceslop.records.v1';

export function createBrowserRecordStore(): RecordStore {
  // Memory mirror: keeps the session coherent when reads or writes throw.
  let mem: string | null = null;
  const read = (): string | null => {
    try {
      return window.localStorage.getItem(STORAGE_KEY);
    } catch {
      return mem;
    }
  };
  const write = (v: string): void => {
    mem = v;
    try {
      window.localStorage.setItem(STORAGE_KEY, v);
    } catch {
      // quota exceeded / disabled storage: memory mirror stays authoritative
    }
  };
  return createRecordStore(read, write);
}
```
