# M1 Plan 01 — Keyboard Input

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Map physical keys to game input with a pure, tested core and a thin DOM binding.

**Architecture:** `setKey` is a pure function over `RawInput` (fully tested). `attachKeyboard` only wires DOM events to `setKey` and returns a detach function; it is verified manually in the browser.

**Tech Stack:** TypeScript (strict), vitest.

**Spec:** `docs/SPEC-M1.md` §7 (key map), plus Plan 00 types.

## Global Constraints

- TypeScript strict mode, no `any` in game code.
- No external physics engine, ever.
- `attachKeyboard` must `preventDefault()` game keys so arrows/space never scroll the page.
- Key map is SPEC-M1 §7 verbatim: throttle Up/W, brake Down/S, steer Left-Right/A-D, drift Space/Shift, reset R, restart Enter.
- `npm run build` must stay green.

- [ ] **Step 3: Write minimal implementation**

```ts
import type { RawInput } from './types';

const GAME_CODES = new Set([
  'ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight', 'Space',
  'KeyW', 'KeyA', 'KeyS', 'KeyD', 'KeyR', 'Enter', 'ShiftLeft', 'ShiftRight',
]);

export function setKey(s: RawInput, code: string, down: boolean): void {
  switch (code) {
    case 'ArrowUp':
    case 'KeyW':
      s.throttle = down;
      break;
    case 'ArrowDown':
    case 'KeyS':
      s.brake = down;
      break;
    case 'ArrowLeft':
    case 'KeyA':
      s.left = down;
      break;
    case 'ArrowRight':
    case 'KeyD':
      s.right = down;
      break;
    case 'Space':
    case 'ShiftLeft':
    case 'ShiftRight':
      s.drift = down;
      break;
    case 'KeyR':
      if (down) s.reset = true;
      break;
    case 'Enter':
      if (down) s.restart = true;
      break;
    default:
      break;
  }
}

export function consumeActions(s: RawInput): { reset: boolean; restart: boolean } {
  const out = { reset: s.reset, restart: s.restart };
  s.reset = false;
  s.restart = false;
  return out;
}

export function attachKeyboard(s: RawInput): () => void {
  const down = (e: KeyboardEvent): void => {
    if (GAME_CODES.has(e.code)) e.preventDefault();
    setKey(s, e.code, true);
  };
  const up = (e: KeyboardEvent): void => {
    setKey(s, e.code, false);
  };
  window.addEventListener('keydown', down);
  window.addEventListener('keyup', up);
  return () => {
    window.removeEventListener('keydown', down);
    window.removeEventListener('keyup', up);
  };
}
```
